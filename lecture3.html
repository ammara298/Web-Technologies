LECTURE 03

HTML Fundamentals

Understanding HTML structure, elements, tags, attributes, links, images, tables and lists.

01

Introduction to HTML

HTML (HyperText Markup Language) is used to structure content on web pages. It provides elements that describe headings, paragraphs, links, images, tables and other content.

02

HTML Document Structure

A basic HTML document contains a document type declaration, a head section and a body section.

Basic Structure

DOCTYPE → HTML → HEAD + BODY

  • DOCTYPE: Declares the document type.
  • Head: Contains metadata and document information.
  • Body: Contains the visible page content.

Practical HTML Document Structure

<!DOCTYPE html>
<html>
<head> <title>Page Title</title>
<body> Webpage Content
</html>

06

Hyperlinks

Hyperlinks connect one resource or page to another. HTML supports different types of links.

  • Absolute Links: Point to a complete external URL.
  • Relative Links: Point to a resource relative to the current page.
  • Fragment Links: Navigate to a specific location within a page.

07

Images and Media

HTML provides elements for including visual and multimedia content in web pages.

  • Images can be included using the image element.
  • Alternative text helps describe images when they cannot be viewed.
  • HTML5 provides native support for audio and video.

HTML5 and Modern Web Features

HTML5 introduced new elements and features that support modern web development and multimedia.

  • New semantic elements
  • Native audio and video
  • Canvas
  • Modern form input types
  • Additional HTML attributes
  • Responsive design support through the viewport setting
