LECTURE 01

Web Technologies Fundamentals

An introduction to the Internet, World Wide Web, web communication, standards, applications and web architecture.

01

Internet and World Wide Web

The Internet is a global network of interconnected computer networks that allows devices to communicate and exchange information.

The World Wide Web is a service that operates over the Internet and allows users to access interconnected web pages and resources through web browsers.

02

Request and Response

Web communication commonly follows a request-response model. A client, such as a web browser, sends a request to a web server. The server processes the request and sends an appropriate response back to the client.

Basic Flow

Client → Request → Web Server → Response → Client

Practical: HTTP Request & Response

Client / Browser HTTP Request
→
Web Server Processes Request
→
Client / Browser HTTP Response

The browser sends a request to the server, and the server processes it and sends a response back to the browser.

03

URL and URI

A URL (Uniform Resource Locator) identifies the location of a resource and provides a way to access it.

A URI (Uniform Resource Identifier) is used to identify a resource. A URL is a commonly used type of URI that also provides information about how to locate the resource.

04

HTTP and HTTPS

HTTP (HyperText Transfer Protocol) is used for communication between web clients and servers.

HTTPS is the secure version of HTTP. It provides encrypted communication between the client and server.

Practical: URL and HTTP/HTTPS

Example URL

https://www.example.com/products?id=25

https → Protocol www.example.com → Domain /products → Path ?id=25 → Query

HTTP

Transfers web data without encryption.

HTTPS

Uses encryption to provide a more secure connection.

05

Domain Name System (DNS)

DNS translates human-readable domain names into IP addresses that computers can use to locate servers.

Example

Domain Name → DNS → IP Address → Web Server

06

Web Hosting

Web hosting provides the resources and infrastructure required to make a website available on the Internet. Website files are stored on a server so users can access them through the Web.

07

Web Standards and Organizations

Web technologies are developed and maintained through standards and specifications created by different organizations.

  • W3C — World Wide Web Consortium
  • WHATWG — Web Hypertext Application Technology Working Group
  • ECMA — develops standards including ECMAScript
  • IETF — develops Internet standards and protocols
08

Types of Web Applications

Web applications can be categorized according to how their content is generated and delivered.

  • Static Web Application: Content is generally fixed and delivered as stored.
  • Dynamic Web Application: Content can be generated or changed according to data and user interaction.
  • MPA: Multi-Page Application where different pages are loaded during navigation.
  • SPA: Single-Page Application where the application updates content without loading a completely new page for every interaction.
  • PWA: Progressive Web Application combining web technologies with app-like capabilities.
09

Web Application Architecture

Architecture describes how the different parts of a web application are organized and communicate with each other.

One-Tier

Components operate within a single layer.

Two-Tier

The client communicates directly with a server or data layer.

Three-Tier

Presentation, application logic and data are separated into different layers.

N-Tier

The application is divided into multiple logical or physical layers.

Key Takeaways

  • The Internet and Web are related but different concepts.
  • Web communication commonly follows a request-response model.
  • URLs and URIs are used to identify web resources.
  • HTTP and HTTPS support communication between clients and servers.
  • DNS helps translate domain names into IP addresses.
  • Web applications can use different application types and architectures.
