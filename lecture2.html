LECTURE 02

Web Applications & Architecture

An overview of web application types and the architectural models used to organize web systems.

01

Web Applications

Web applications are software applications that are accessed through a web browser. They use web technologies to provide functionality and interact with users.

Depending on how information is delivered and updated, web applications can be organized into different types.

Practical: Types of Web Applications

Static

Fixed content that changes rarely.

Dynamic

Content can change based on data or users.

MPA

Loads separate pages for different requests.

SPA

Updates content without fully reloading the page.

PWA

Web applications with app-like features.

02

Static Web Applications

A static web application generally delivers pre-created web pages to the client. The content remains relatively fixed unless the files are manually changed.

Key Idea

Stored content → Web Server → Browser

03

Dynamic Web Applications

Dynamic web applications can generate or change content according to user requests, application logic, or available data.

These applications can interact with databases and other server-side resources.

04

Multi-Page Applications (MPA)

A Multi-Page Application consists of multiple web pages. Navigation between different sections generally loads another page from the server.

Multiple Pages

Different sections of the application are represented by separate pages.

Page Navigation

Moving between sections can require loading another page.

05

Single-Page Applications (SPA)

A Single-Page Application loads a main web page and can update its content dynamically without loading a completely new page for every interaction.

Key Idea

One main page → Dynamic content updates

06

Progressive Web Applications (PWA)

Progressive Web Applications use web technologies while providing features that can give users an app-like experience.

07

Web Application Architecture

Application architecture describes how different parts of a system are organized and how they communicate with each other.

One-Tier Architecture

Application components operate within a single layer.

Two-Tier Architecture

The client communicates directly with a server or data layer.

Three-Tier Architecture

Presentation, application logic and data are separated into different layers.

N-Tier Architecture

The system is divided into multiple logical or physical layers.

Practical: Web Application Architecture

One-Tier

All components work together in one layer.

Two-Tier

Client communicates directly with the server or database.

Three-Tier

Presentation, application and data layers are separated.

N-Tier

Application is divided into multiple specialized layers.

Key Takeaways

  • Web applications provide functionality through web technologies and browsers.
  • Static and dynamic applications differ in how their content is delivered.
  • MPA uses multiple pages while SPA can update content within a single main page.
  • PWA provides web-based functionality with app-like capabilities.
  • Web applications can be organized using one-tier, two-tier, three-tier and N-tier architecture models.
