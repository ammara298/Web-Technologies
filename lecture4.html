LECTURE 04

HTML5, Semantic Elements & Forms

Exploring HTML5 features, semantic structure, responsive design, forms, validation and accessibility.

01

HTML5

HTML5 introduced new elements, attributes and features that support modern web development. It also provides improved support for multimedia and structured web content.

HTML5 Features

Semantic elements • Audio • Video • Canvas • Modern form controls

Practical HTML5 Features

Semantic Elements <header>, <nav>, <main>, <section>
Multimedia <audio> and <video>
Modern Forms Email, date and number input types
02

Semantic HTML Elements

Semantic elements describe the purpose of the content they contain. They make the structure of a webpage easier for developers, browsers and assistive technologies to understand.

<header>

Represents introductory or navigational content for a page or section.

<nav>

Contains navigation links.

<main>

Represents the main content of the document.

<section>

Represents a thematic section of content.

<article>

Represents an independent piece of content.

<aside>

Represents related or secondary content.

<footer>

Represents footer information for a page or section.

Responsive design allows a website to adapt its layout and content to different screen sizes and devices.

The viewport setting helps browsers control the dimensions and scaling of a webpage on different devices.

04

HTML5 Multimedia

HTML5 provides native elements for multimedia content without requiring additional browser plugins.

  • Audio: Used to embed audio content.
  • Video: Used to embed video content.
  • Canvas: Provides an area where graphics can be rendered using scripts.
05

HTML Forms

Forms allow users to enter and submit information. They are commonly used for registration, login, search and other interactive features.

Important Form Attributes

action → specifies where form data is sent
method → specifies how the data is submitted

06

Form Controls

HTML provides different controls for collecting different types of user input.

  • Text input
  • Email input
  • Password input
  • Number input
  • Date input
  • Select/drop-down list
  • Textarea
  • Buttons
07

HTML5 Form Validation

HTML5 provides built-in client-side validation features that can help ensure that users enter appropriate information before a form is submitted.

required

Specifies that a field must contain a value.

pattern

Allows a value to be checked against a specified pattern.

min

Defines a minimum permitted value.

max

Defines a maximum permitted value.

08

Accessibility

Accessible web pages are designed so that people with different abilities can use and understand the content.

  • Use clear labels for form controls.
  • Provide meaningful alternative text for images.
  • Use fieldset and legend where appropriate for related form controls.
  • Provide clear feedback to users.

Practical Accessibility Example

Contact Preferences

Labels and legends help users understand and interact with form controls.

09

Client-Side and Server-Side Validation

Client-Side Validation

Validation takes place in the user's browser before information is sent to the server.

Server-Side Validation

Validation takes place on the server after the submitted data is received.

Key Takeaways

  • HTML5 provides modern elements and features.
  • Semantic elements improve the structure and meaning of web content.
  • Responsive design helps websites work across different screen sizes.
  • Forms collect information from users.
  • HTML5 provides built-in validation features.
  • Accessibility should be considered when designing web pages and forms.
