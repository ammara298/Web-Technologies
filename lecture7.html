CSS Floats & Clearing

Floats can move elements to the left or right and allow surrounding content to flow around them.

CSS FLOAT

Understanding Float Layouts

CSS float allows an element to move toward the left or right side of its containing block. Other content can flow around the floated element.

Clearing can be used when following content should move below the floated element instead of wrapping around it.

Clear / Clearfix: Used to control the effect of floating elements on surrounding layout.
