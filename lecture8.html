03

CSS Custom Properties

CSS variables make repeated design values easier to maintain and reuse.

CSS Variables

Reusable Design Tokens

--brand Primary color
--surface Background
--radius Corner size 
:root {
  --brand: #0284c7;
  --surface: #ffffff;
  --radius: 12px;
}

.card {
  color: var(--brand);
  background: var(--surface);
  border-radius: var(--radius);
}
04

Media Queries

Media queries apply CSS according to conditions such as viewport width and orientation.

Responsive Design

Responsive Cards

Resize the browser window to see the layout change.

Desktop Cards appear in multiple columns.
Tablet Columns adjust according to screen width.
Mobile Cards move into a single column. 
@media (max-width: 768px) {
    .media-demo {
        grid-template-columns: 1fr;
    }
}
05

Feature Queries & @supports

@supports checks whether a browser understands a CSS feature before applying enhanced styling.

Progressive Enhancement

Flexbox

ENHANCED

CSS Grid

Grid can be used when the browser supports it. 

.layout {
    display: flex;
}

@supports (display: grid) {
    .layout {
        display: grid;
    }
}

Cross-Browser Compatibility

Websites should remain usable across different browsers and devices.

Compatibility Checklist

Before Deployment

✓ Standard CSS

Prefer current standards-based CSS.

✓ Fallbacks

Provide alternatives for unsupported features.

✓ Browser Testing

Check Chrome, Edge, Firefox and Safari.

✓ Responsive Testing

Test desktop, tablet and mobile layouts.
