LECTURE 06

CSS Layout & Box Model

Understand how CSS controls the size, spacing, layout and visual appearance of elements.

01 CSS Box Model

The CSS box model describes how every HTML element is represented as a rectangular box. It consists of content, padding, border and margin.

Box Model Components

Content → Padding → Border → Margin

Practical CSS Box Model

Content

02 Components of the Box Model

Content

The content area contains the actual text, image or other information inside an element.

Padding

Padding is the space between the content and the element's border.

Border

A border surrounds the content and padding of an element.

Margin

Margin is the space outside the border that separates an element from other elements.

03 Margin Collapsing

Margin collapsing can occur between certain block-level elements. When vertical margins meet, they may combine into a single margin instead of adding together.

Important:

Margin collapsing mainly affects vertical margins between block-level elements.

04 Box-Sizing Property

The box-sizing property controls how the width and height of an element are calculated.

content-box

This is the default box-sizing value. The specified width and height apply to the content area.

border-box

The specified width and height include the content, padding and border.

05 Width, Height and Size Constraints

CSS provides properties for controlling the dimensions of elements.

  • width: Sets the width of an element.
  • height: Sets the height of an element.
  • min-width: Defines the minimum width of an element.
  • max-width: Defines the maximum width of an element.
  • min-height: Defines the minimum height of an element.
  • max-height: Defines the maximum height of an element.

06 Overflow

The overflow property controls what happens when content is larger than the available size of its element.

Visible

Content can extend outside the element.

Hidden

Content that overflows the element is hidden.

Scroll

Scrollbars are provided for accessing overflowing content.

Auto

Scrollbars are provided when they are needed.

07 Display Property

The CSS display property controls how an element is displayed and how it participates in the layout.

Block

A block element normally starts on a new line and takes the available width.

Inline

An inline element normally takes only the space required by its content.

Inline-Block

Combines characteristics of inline and block-level elements.

None

Removes the element from the layout.

08 Borders, Shadows and Spacing

CSS provides properties that help create clear visual separation and improve the appearance of elements.

  • Borders: Define the boundary around an element.
  • Shadows: Add visual depth around elements.
  • Spacing: Padding and margin control the space inside and outside elements.

11 Key Takeaways

  • The CSS box model consists of content, padding, border and margin.
  • The box-sizing property controls how element dimensions are calculated.
  • Width, height and min/max properties control the size of elements.
  • Overflow controls content that exceeds the available space.
  • The display property controls how elements participate in a layout.
  • Borders, shadows, spacing and typography improve the visual presentation of a website.
