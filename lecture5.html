LECTURE 05

CSS Fundamentals

Learn how Cascading Style Sheets are used to style and improve the appearance of web pages.

01 Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the presentation and appearance of HTML elements on a web page.

CSS Syntax

A CSS rule consists of a selector and a declaration block containing one or more property-value pairs.

02 Types of CSS

CSS can be applied to HTML documents in three main ways.

Inline CSS

CSS is written directly inside an HTML element using the style attribute.

Internal CSS

CSS rules are written inside the <style> element in the HTML document.

External CSS

CSS is stored in a separate stylesheet and connected to HTML using the link element.

Recommended for multiple pages:

External CSS allows the same stylesheet to be used across multiple web pages and helps maintain a consistent design.

03 CSS Selectors

Selectors identify the HTML elements that CSS rules should style.

Element Selector

Selects HTML elements by their element name.

Class Selector

Selects elements using a class attribute.

ID Selector

Selects an element using its unique ID.

Attribute Selector

Selects elements based on their attributes and attribute values.

04 Other CSS Selectors

  • Grouping Selector: Applies the same style to multiple selectors.
  • Descendant Selector: Selects elements inside another element.
  • Child Selector: Selects direct children of an element.
  • Adjacent Sibling Selector: Selects an element immediately following another element.
  • General Sibling Selector: Selects sibling elements that share the same parent.
  • Universal Selector: Selects all elements on a page.

06 Cascade, Specificity and Inheritance

CSS uses the cascade to determine which styles should be applied when multiple rules target the same element.

  • Cascade: Determines which CSS rule is applied when multiple rules conflict.
  • Specificity: Determines the priority of selectors.
  • Inheritance: Allows some CSS properties to be inherited from a parent element by its child elements.

07 Colors, Fonts and Text

CSS provides different properties for controlling the visual appearance of text and other elements.

Colors

Color properties can be used to control the color of text and backgrounds.

Fonts

Font family, font size, font weight and font style can be controlled using CSS.

Text

Text alignment, decoration, transformation, line height and letter spacing can be styled.

09 Key Takeaways

  • CSS controls the presentation and appearance of HTML documents.
  • CSS can be applied using inline, internal, or external styles.
  • Selectors determine which HTML elements receive CSS styles.
  • Pseudo-classes and pseudo-elements provide additional styling capabilities.
  • Cascade, specificity and inheritance affect how CSS rules are applied.
  • CSS can control colors, fonts, text and backgrounds.
